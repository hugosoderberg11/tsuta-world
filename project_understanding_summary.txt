# Project Understanding Summary

## What this is
Claude export of a static TSUTA-WORLD corporate site. Not a Node/npm app. Preview locally with `start-local.bat` or `py -m http.server 5500`.

## Main files
- `index.html` — TOP page (dc-runtime). Footer updated per client spec; NEWS links to post pages.
- `support.js`, `image-slot.js` — dc-runtime (do not edit unless asked).
- `middleware.js` — Vercel Routing Middleware (Basic auth for production)
- `package.json` — Vercel deploy only (`@vercel/functions`); not used for local preview
- `start-local.bat` — double-click to start local preview (Python http.server on port 5500)
- `site.css` — shared styles for subpages.
- `post.html` — 新着情報一覧
- `post-*.html` — article detail pages (content from tsuta-world.com)
- `company.html` — 会社情報 (from tsuta-world.com/company/)
- `agency.html` — 代理店募集 (from existing site partner-recruitment text)
- `creative-marketing.html` — クリエイティブ＆マーケティング詳細（Hero / SERVICES / WORKS / CONTACT / Footer）
- `contact.html` — お問い合わせ (TEL/hours/address from TOP)
- `assets/ai-dx-training.png` — AI/DX研修（サービス03）サムネイル
- `assets/service-fanstep.jpg` / `service-kitabuzz.jpg` / `service-web.jpg` / `service-anime.jpg` / `service-creative.jpg` / `service-apparel.jpg` — TOP SERVICES large-card banners (1024×576 JPEG, shown uncropped)
- `assets/media-eejanai.png` — TV/MEDIA カンニング竹山のイチバン研究所 thumbnail
- `assets/media-ichiban.png` — TV/MEDIA ええじゃない課Biz thumbnail
